**谷歌风控的三个核心维度**

谷歌判断一个注册行为是否"真实"，主要看三样东西：

- **网络环境**：你用的 IP 是不是住宅 IP、是不是被大量注册行为用过的"脏 IP"、IP 所在地区跟你填的个人信息是否一致。公共节点、机房 IP、被多人共享的 VPN 节点，基本一注册就被标记。

- **手机号质量**：一个手机号被多次用于验证、虚拟号段、被谷歌标记为高风险的号码，都会直接报"此号码无法用于进行验证"。

**2026 年新增的二维码验证**

这两年谷歌在部分地区和部分网络环境下，强制引入了二维码验证流程。简单说就是注册到一半，系统让你用手机扫描一个二维码，然后发送一条预编辑好的短信到指定号码。这个步骤**没法跳过**，它的目的不是验证你有没有手机，而是判断当前注册行为是不是接近真实用户。很多人卡在这一步，就是因为用的网络环境太"假"，谷歌直接上了扫码这道关卡。
